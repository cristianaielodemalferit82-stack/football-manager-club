# Football Manager Club ⚽

## Descripción

Football Manager Club es una aplicación web desarrollada para la gestión de jugadores de un club de fútbol.

La aplicación permite registrar, consultar, editar y eliminar jugadores utilizando tecnologías web modernas.

---

## Tecnologías utilizadas

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express

### Base de datos

- MongoDB
- Mongoose

### Control de versiones

- GitHub

## Funcionalidades

- Añadir jugadores.
- Consultar jugadores.
- Editar jugadores.
- Eliminar jugadores.
- Gestionar información deportiva.
