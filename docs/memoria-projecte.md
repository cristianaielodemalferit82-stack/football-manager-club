# Memòria del Projecte

## Nom del projecte

Football Manager Club

## Descripció

Football Manager Club és una aplicació web desenvolupada per a la gestió de jugadors d'un club de futbol.

L'aplicació permet administrar informació dels jugadors mitjançant una interfície web moderna i una base de dades MongoDB.

---

## Objectius

- Gestionar jugadors.
- Registrar informació esportiva.
- Consultar dades dels jugadors.
- Modificar informació existent.
- Eliminar registres.

---

## Tecnologies utilitzades

### Frontend

## Guia d'estils

S'ha utilitzat una temàtica futbolística amb colors inspirats en el camp de futbol:

- Verd principal
- Blanc
- Blau secundari

Disseny responsive i orientat a la usabilitat.

---

## Prototipat

La interfície principal mostra:

- Llista de jugadors.
- Botó per afegir jugadors.
- Opcions d'editar i eliminar.
